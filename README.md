# 枕书（Pillowbook）

iOS 原生阅读 App。本仓库是**发行仓**：只存放 GitHub Actions 构建的 unsigned IPA 与版本说明，**不含源码**（源码在私有仓库 `Aegink/Pillowbook`）。

## 安装方式

侧载自签安装（无 App Store / TestFlight）：

1. 从 [Releases](https://github.com/Aegink/Pillowbook-Releases/releases) 下载 unsigned IPA。
2. 使用 AltStore、Sideloadly 或 Xcode 等工具以自己的 Apple ID 自签安装。
3. 系统要求：iOS / iPadOS 17+。

## 免责声明

- 枕书是一个**阅读工具**，本身不含任何书籍内容、书源或网络内容服务。
- 用户需自行导入书源，使用过程中产生的行为与责任由用户自行承担。
- 本应用仅用于学习与个人使用。
